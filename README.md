# 广东海洋大学 · 正方教务课表导出（ICS + Excel + 课刻）

油猴（Tampermonkey）脚本：在广东海洋大学正方教务「个人课表查询」https://wfw.gdou.edu.cn/页面一键导出——

- **ICS 日历**：导入 Google Calendar / Outlook / 手机日历，支持单双周、调课单周
- **普通 Excel**：周视图 + 课程明细两个工作表
- **课刻专用 xlsx**：`desktop-course-widget`（课刻）直接导入的单工作表网格，**右侧附带作息时间表，课刻导入后自动应用作息**

适用页面：`jw.gdou.edu.cn` / `wfw.gdou.edu.cn` 的 `kbcx/xskbcx_cxXskbcxIndex.html`（个人课表查询）。

---

## 功能特性

- ✅ 三个导出按钮 + 「选择本学期第一个星期一」日期选择框，默认 **2026-08-31**（可自行修改）
- ✅ 节次正则兼容 `(1-2节)`、`(3~4节)`、`(单节)`、`(1—2节)` 等分隔符
- ✅ 周次解析兼容：`1-5周,7-8周`、`第3周`（调课单周）、`1-3周(单),7-13周(单)`、`2-16周(双)`、`◎` 装饰图标、`【调】` 前缀、全角括号
- ✅ 新版界面（td 无 id）自动兜底解析：按「星期X」表头列 + 行首节次定位课程
- ✅ 课刻专用 xlsx 右侧附 **10 节作息时间表**（节次 / 开始 / 结束），课刻 `desktop-course-widget` 导入后自动更新课表时间
- ✅ 解析失败不再臆造 "1-20 周"：周次解析失败时控制台告警、课表留空（课刻侧安全跳过），并在页面结构异常时输出结构诊断

## 安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox）
2. 打开 [GDOU_课表导出_ICS_Excel.user.js](./GDOU_课表导出_ICS_Excel.user.js)，Tampermonkey 会提示安装
3. 登录广东海洋大学教务系统（`jw.gdou.edu.cn` 或 `wfw.gdou.edu.cn`），进入 **个人课表查询**，页面右上角出现操作按钮

## 使用方法

1. **生成课表**：导出 `.ics` 文件，导入任意日历软件（Google Calendar 需要自行设置课程颜色）
2. **导出 Excel**：普通 Excel，含「课表」周视图（跨节课程自动合并单元格）与「课程明细」两个工作表
3. **导出课刻**：生成 `课刻-课程表.xlsx`，在 [课刻 desktop-course-widget](https://tyr1onx.github.io/desktop-course-widget/) 中点击「导入新课表」选择该文件，**课刻会自动读取右侧作息时间表并按新的作息展示**

日期选择框：确认本学期第一个星期一的日期（默认 `2026-08-31`，对应 2026-2027 学年第 1 学期），ICS 的周次计算以此为准。

## 常见问题

| 现象                 | 说明                                                                |
| ------------------ | ----------------------------------------------------------------- |
| 提示「未找到课表表格」        | 请确认页面是「学生课表查询」并已加载课表（新版界面已自动兜底解析，若仍失败请打开 F12 控制台，把红色诊断输出发到 Issue） |
| 某课程周次解析失败（控制台橙色告警） | 脚本不会臆造周次，该课程留空并在课刻中安全跳过，请附上该课程的原文文本                               |
| 课刻导入后时间不对          | 请确认导出的是本脚本的「导出课刻」文件（带右侧作息时间表），并核对脚本头部 `TIME` 作息                   |
